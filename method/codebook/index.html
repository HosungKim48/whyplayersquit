Quit-reason codebook

Codebook v1 · part of the Method

The 12 categories the labeling model used for every WARDOGS review, in every language. Built from 300 reviews I read by hand and approved before the full run.

The task

You read one negative Steam review of the game WARDOGS (a large-scale PvP tactical shooter in Early Access) and decide why the reviewer is unhappy or quitting. Reviews can be in any language; the categories are the same for every language. Read the review in its original language, then answer in English.

Field Type Rule
primary_reason one category code The main reason. Pick the reason the reviewer gives the most weight: the one tied to quitting/refunding, stated most strongly, or given the most space. If tied, take the first one mentioned.
secondary_reason category code or null A second, different reason that is clearly stated. Null if there is none. Never repeat primary_reason.
confidence number 0–1 How sure you are about primary_reason. ~0.9 = explicit and unambiguous; ~0.6 = two reasons compete or the text is short; ≤0.4 = mostly guessing.
short_evidence string, ≤15 words, English Paraphrase of the part of the review that supports primary_reason. No quotes longer than 3 words, no names, no IDs, no profanity.

Tie-breaks and general rules

  • Primary reason = the one tied to quitting or refunding, stated most strongly, or given the most space. If tied, the first one mentioned.
  • Secondary reason must differ from the primary. In the analysis, a secondary of “unclear / other” or one equal to the primary counts as none.
  1. Judge only what the review says; don't infer from the date or language. (Date context is in the codebook only to explain events, not to guess.)
  2. Language-independent: same rules for every language. Slurs or ethnic generalizations are labeled by the underlying complaint; short_evidence stays neutral.
  3. Updated reviews ("Update:", "Season 3 edit"): use the most recent complaint as primary.
  4. Review is really a feature request list: pick the issue framed as the reason for the negative vote.
  5. Never output a code that isn't in the table.

Categories

Progression wipe progression_wipe

Definition
The reviewer is upset that a season reset wiped their levels, unlocks, money or gold.
Include
"wipe", "reset", "清档 / 删档 / 数据全清", "вайп", losing unlocks at Season 2/3, fear that progress will be wiped soon.
Exclude
Slow progress or gear gap with no mention of a reset → grind_gear_gap. Losing in-match gear after a server crash → servers_access.
Edge cases
Wipe + grind together ("slow grind, and then it gets wiped") → primary progression_wipe if the reset is the punchline, secondary grind_gear_gap. A ban that also wiped the account → developer_trust_enforcement.
Examples (paraphrased)
  • Spent a whole season unlocking a tank, then Season 2 wiped everything back to level 0.
  • Wipes every few weeks only reward people who play all day; pointless for everyone else.

Grind & gear gap grind_gear_gap

Definition
Leveling/unlocking takes too long, and high-level players with better armor/weapons/vehicles dominate newer or casual players.
Include
slow XP, "grind", "肝", gear locked behind levels, level-4 armor vs starter guns, "game for the unemployed / no-lifers", hostile to newcomers, no level-based matchmaking, "late joiners can't catch up".
Exclude
A specific weapon/vehicle being too strong for everyone → balance. Season reset → progression_wipe.
Edge cases
"Imbalance between new and old players" is grind_gear_gap, not balance. "Helicopters dominate because AA unlocks at high level" → grind_gear_gap if the complaint is the unlock level, balance if it is the helicopter's power.
Examples (paraphrased)
  • New players start with junk guns and no armor while veterans tank a full magazine.
  • Leveling a class takes forever; only people who play eight hours a day can compete.

Ping cap / region access ping_cap_region_access

Definition
The reviewer can't play (or is kicked) because of the ping limit, region locking, or country-level access restrictions.
Include
175 ms cap, "kicked for high ping", "region lock / 锁区 / 지역락 / 핑킥", being stuck on cheater-filled Asian servers because NA is blocked, "can't play from Russia without VPN", calling the ping policy "racial/regional discrimination", "sold the game then blocked us", demands for refunds because of the lock.
Exclude
General lag or high ping with no limit/kick mentioned → servers_access. Reviewer asking for a region lock or stricter ping to stop cheaters → cheaters.
Edge cases
Mentions both cheaters and the lock ("can't stop cheaters so they punish normal players") → primary ping_cap_region_access, secondary cheaters. Friends mentioned → secondary social_teammates. Complaints that the cap was later raised (wanting it strict) → ping_cap_region_access, secondary cheaters.
Examples (paraphrased)
  • Bought it to play with friends overseas; the new ping limit kicks me so we can't play together.
  • Asian servers are full of cheaters and now the ping kick stops us from escaping to NA servers.

Servers & access servers_access

Definition
Online/service problems stop or ruin play: queues, login/connection failures, server crashes, DDoS, disconnects, lag, too few/no nearby servers.
Include
launch queues (e.g. 200k in line), "can't get in", connection errors to servers, "server blew up and I lost my gear money", DDoS on Asian servers, empty server browser, no servers in my region (e.g. no South Africa server) without mention of the cap.
Exclude
The game crashes on my PC / FPS / bugs → technical_client. Kicked by the ping limit → ping_cap_region_access.
Edge cases
Streamers getting priority during the queue → servers_access primary, developer_trust_enforcement secondary. "Can't get in" with an anti-cheat error code → technical_client.
Examples (paraphrased)
  • Sat in a queue of 300,000 for hours, then got an error and was sent back.
  • Servers get DDoSed every evening; four matches, four server crashes.

Technical (game client) technical_client

Definition
The game program fails on the player's machine: crashes, freezes, low FPS, poor optimization, bugs, error codes, anti-cheat software conflicts, unsupported platforms.
Include
crash every few minutes, BSOD, DirectX/ACCESS_VIOLATION errors, infinite loading, keybind bugs, vehicles glitching, "doesn't run on Linux/Steam Deck", anti-cheat login failed, "virus-like" PC freezes after install.
Exclude
Server-side outages/queues/disconnects → servers_access. Cheaters using hacks → cheaters.
Edge cases
"Lots of bugs and poor design, not worth $40" → price_value only if value is the main point; otherwise technical_client.
Examples (paraphrased)
  • Game crashes every 2–3 minutes; unplayable.
  • Anti-cheat conflicts with my other software and blue-screens the PC.

Cheaters & exploiters cheaters

Definition
Cheaters, hackers or exploit/money farmers ruin matches, and anti-cheat or admins don't deal with them.
Include
aimbot, wallhack, "挂 / 外挂 / 刷子 / 핵 / читеры / xiter", flying vehicles from hacks, cheat ads in chat, "anti-cheat does nothing", exploiters going unpunished, players asking for region lock/separate Chinese servers to stop cheaters.
Exclude
Complaints about the ping cap/region lock as the response to cheaters → ping_cap_region_access. Being banned unfairly → developer_trust_enforcement.
Edge cases
Ethnic slurs about cheaters → still cheaters; short_evidence must stay neutral ("many cheaters from one region").
Examples (paraphrased)
  • Every lobby has players with perfect aim who always know where you are.
  • Anti-cheat is useless; reports go nowhere and hackers keep coming back.

Balance balance

Definition
Specific weapons, vehicles, tactics, economy rewards or team sides are too strong or too weak.
Include
grenade-launcher helicopters, infinite mortars, tanks not dying to RPGs, armor/TTK tuning, one team (e.g. Green) always winning, team-size imbalance, nerfed transport rewards, equipment prices making people afraid to fight.
Exclude
Strength coming from level/unlocks → grind_gear_gap. "The whole concept is boring" → gameplay_design.
Edge cases
"Devs can't balance" with no detail → balance at confidence ~0.6.
Examples (paraphrased)
  • Helicopters with grenade launchers wipe everything and any counter buys only a minute.
  • One team sits in a tower with the hot zone forever; games are lopsided.

Gameplay & design gameplay_design

Definition
The core design isn't fun for the reviewer: pace, travel time, camping, base building, map, tutorial/onboarding, presentation, repetitiveness or lack of content.
Include
"walking simulator", long rides to the front, dying to unseen snipers, campers in buildings/bushes, FOB/base-building meta, unskippable tutorial, dated graphics, "worse Arma/Squad/Battlefield copy", "nothing to do after a week", "not my kind of game".
Exclude
Specific overpowered items → balance. Teammates' behavior → social_teammates. Technical FPS problems → technical_client.
Edge cases
"Not fun" with a concrete design detail → gameplay_design; "trash game" with nothing else → unclear_other.
Examples (paraphrased)
  • Spent most of my hours as a corpse or a passenger, barely any actual fighting.
  • Pace is snail-like; you wait ten minutes for one gunfight.

Social & teammates social_teammates

Definition
Problems with other people on your side or playing together: friends can't join (non-ping reasons), solo-unfriendly, toxic/griefing/team-killing/looting teammates, missing squad/party tools.
Include
teammates stealing gear while reviving, team kills without punishment, griefers, no squad/lobby party, "needs a group of friends to be fun", toxic chat.
Exclude
Can't play with friends because of the ping cap/region lock → ping_cap_region_access (social_teammates as secondary). Cheaters → cheaters.
Edge cases
"Bought to play with friends, unable to play with friends" with no cause given: if posted on/after 2026-10-21 and no other clue, still social_teammates at confidence ≤0.5 (do not guess the ping cap).
Examples (paraphrased)
  • Teammates loot your whole kit when they revive you and team-kill for vehicles.
  • Solo play is miserable; nobody communicates or helps.

Price & value price_value

Definition
The game isn't worth what it costs, or in-game monetization/cosmetic prices are unreasonable.
Include
"not worth $40/€40 — maybe $20", regret the purchase on value grounds, skins/gold prices absurd, "paid for an unfinished game".
Exclude
Refund demand caused by another reason (lock, bans, crashes) → that reason. Bare "refund" → unclear_other.
Edge cases
Value + bugs → price_value primary only if price/worth is the explicit conclusion.
Examples (paraphrased)
  • Feels like a 2010 game; not worth €40, maybe €20.
  • Skins cost an absurd amount of gold that a normal player will never earn.

Developer trust & enforcement developer_trust_enforcement

Definition
The reviewer distrusts the developer because of how it treats players: wrongful bans, revoked keys, removed features, favoritism, inconsistent rules, poor or arrogant communication.
Include
false/permanent bans, ban appeals ignored, key revoked, family sharing removed, streamers getting priority/exemptions, exploiters only lightly punished, devs "begging for reviews", AI-written replies, dodging questions in a podcast, "incompetent devs" with specifics about conduct.
Exclude
Bans as part of the ping/region policy → ping_cap_region_access. Devs failing to ban cheaters → cheaters. Devs "can't balance" → balance.
Edge cases
"Bad devs = bad game" with nothing else → unclear_other.
Examples (paraphrased)
  • My brother never cheated and got permanently banned; appeal went nowhere.
  • They removed family sharing a week after launch without telling anyone.

Unclear / other unclear_other

Definition
The review gives no usable reason, or its reason fits none of the categories.
Include
insults only, "worst game ever", "you know why", a single emoji/number/error-free joke, bare "refund", positive text with a negative vote and no complaint, off-topic text.
Exclude
Anything with a concrete reason, even a short one ("full of cheaters" → cheaters).
Edge cases
Always set confidence ≤0.5 for unclear_other unless the text is clearly reason-free.
Examples (paraphrased)
  • Garbage game, worst I've ever played.
  • "You know why." (no further text)

Examples are short paraphrases written for the codebook, not quotes from reviewers.
