Which complaints actually come before players quit.

The most common complaint in a game's negative reviews is often not the one that makes players leave. Quit Signals follows games over time: it labels the reason in every negative review, in every language, then checks whether the reviewer kept playing.

How it works

  1. Collect

    Every public Steam review of the game, in every language.

  2. Label

    Each negative review is read in its original language and tagged with its main reason, using a fixed codebook checked by hand.

  3. Follow up

    Steam's playtime data shows whether each reviewer kept playing or stopped.

  4. Report

    Each run publishes a dated report on which complaints come before quitting, by hours played.
